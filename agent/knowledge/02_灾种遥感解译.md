# 灾种遥感解译要点

洪涝(flood)：用 Sentinel-1 SAR 后向散射(VH)穿透云层提取水体，配合 Sentinel-2 NDWI 水分指数上升判断淹没；植被被淹后 NDVI/EVI 下降。融合时 NDWI 与 SAR 水体权重较高。

干旱(drought)：表现为持续的绿度与生产力下降。NDVI/EVI 绝对值在早期可能不敏感，应重点看 GPP/NPP 相对历史同期基线的异常、以及 VCI(植被状态指数)是否贴近历史最低。

冰雹/大风/台风(hail/typhoon)：机械损伤导致冠层结构突变，NDVI 与 NDRE 短期骤降，SAR 后向散射变化亦可佐证；台风常伴涝，NDWI 也参与。

病虫害(pest)：叶绿素与氮素胁迫先于整体绿度变化显现，NDRE 红边指数最敏感，权重最高，NDVI/EVI 作为辅证。

霜冻(frost)：低温冻害造成叶片受损，NDVI 与 NDRE 下降，结合生产力异常综合判断。

通用原则：单期 NDVI 绝对值无法区分"受灾"与"本就长势差/物候不同"，必须结合"灾前灾后变化"与"对多年历史基线的异常"。
