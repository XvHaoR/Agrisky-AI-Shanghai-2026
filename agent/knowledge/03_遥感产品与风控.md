# 遥感产品适用性与风控口径

NDVI/EVI2/NDWI/NDRE：来自 Sentinel-2，分辨率 10–20m，适合地块级。NDVI 高郁闭度易饱和；EVI2 抗饱和；NDWI 测水分；NDRE 测红边/氮素胁迫。

GPP(MOD17A2H)/NPP(MOD17A3HGF)/LAI-FAPAR(MCD15A3H)：来自 MODIS，分辨率 500m，属区域生产力背景。小地块可能不足一个像元，仅作区域参考与交叉校验，不用于地块级面积切割。

生产力气候态异常：GPP/NPP 与"过去若干年同期均值"对比得到异常幅度，比单期绿度更接近真实减产，能剔除常年低产本底。

VCI 植被状态指数 = (当期NDVI − 历史同期最小)/(历史同期最大 − 最小)，1−VCI 记为损失；用于判断当前长势在历史区间中的相对水平。

风险等级口径：风险等级只按减产率与灾种阈值定(高/中/低)，不因赔款金额高低而抬高。预估赔款达到大额阈值(默认 50 万元)只触发"强制人工/财务复核"，不改变风险等级。

风控红线：涉密遥感原始影像与地块边界不上传外部 LLM 云端，只向模型提供运算后的指标与统计结果；阈值/波段/赔付参数由人工锁定在配置文件，AI 只调用不修改；任何案件未经人工审核不得归档定赔。
